# Appendix A -- A Python Toolkit for the Course

Run from the repository root with `python run_all.py appA`, or run a single program directly.

| Script | Book section | What it demonstrates |
|---|---|---|
| `numpy_essentials.py` | A.2 NumPy essentials | arrays, broadcasting, covariance, solving systems, eigen/SVD, least squares, boolean indexing (poverty headcount and gap) |
| `scipy_toolkit.py` | A.3 SciPy and scikit-learn essentials | `scipy.stats` distributions and fitting, BFGS and SLSQP optimisation, `quad` integration, the scikit-learn fit/predict interface |

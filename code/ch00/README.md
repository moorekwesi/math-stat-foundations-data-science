# Chapter 0 -- Mathematical Refresher and Diagnostic Self-Test

Run all scripts from the book root with `python run_all.py ch00` (figures are written to
`figures/`, printed output to `code/ch00/*.out`). All data are illustrative or simulated.

| Script | Book section | What it demonstrates |
|---|---|---|
| `compound_interest.py` | 0.2 | Compounding frequencies, continuous compounding, (1 + 1/m)^m -> e, doubling times and the rule of 70 |
| `log_returns.py` | 0.2 | Simple versus log returns; additivity of log returns; accuracy of ln(1 + x) ~ x |
| `explog_fig.py` | 0.2 | exp(x) and ln(x) as mirror images in y = x, with the tangent 1 + x (figure `ch00_explog.pdf`) |
| `sums_notation.py` | 0.3 | Sigma and product notation, a double sum, mean and variance from their formulas, weighted average, trial balance |
| `derivatives.py` | 0.4 | Difference quotients approaching marginal cost; profit maximisation, MR = MC (figure `ch00_profit.pdf`) |
| `partials.py` | 0.4 | Partial derivatives and the gradient by central differences; a two-product firm solved from its FOCs |
| `riemann.py` | 0.5 | Midpoint Riemann sums, consumer surplus, present value of a continuous income stream, a probability as an area |
| `riemann_fig.py` | 0.5 | Picture of a six-strip midpoint Riemann sum (figure `ch00_riemann.pdf`) |
| `matrices_by_hand.py` | 0.6 | Vector and matrix arithmetic, 2x2 determinant and inverse, market equilibrium, reciprocal cost allocation, NPV as a dot product |
| `proof_checks.py` | 0.7 | Checking cases versus proving; Euler's n^2 + n + 41 counterexample; the accounting equation preserved by every transaction |
| `lab0_basics.py` | 0.8 | Variables, lists, a function, a loop and a decision: a loan amortisation schedule and an NPV rule |
| `lab0_numpy.py` | 0.8 | NumPy arrays, vectorised arithmetic, matrix product, a fitted trend and a first plot (figure `ch00_lab0.pdf`) |
| `lab0_errors.py` | 0.8 | The six most common beginner error messages, NumPy division by zero, built-in help |
